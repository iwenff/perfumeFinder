# Поиск парфюмерии в Telegram

Бот ищет предложения по сохранённым ссылкам на открытые Telegram-каналы. При подключении личного аккаунта поиск также охватывает его подписки. Вы вводите название аромата, выбираете объём и получаете список с ценами и ссылками на публикации. Доступ к меню есть только у владельца.

## 1. Установите Python 3.13 или 3.12

Поддерживаются обе ветки, включая Python 3.13.4. Если Python уже установлен, проверьте его версию в новом окне терминала.

- **Windows.** Отметьте **Add Python to PATH** в установщике Python. В PowerShell проверьте версию командой `py -3.13 --version` или `py -3.12 --version`. [Загрузки для Windows](https://www.python.org/downloads/windows/).
- **macOS.** Установите Python с сайта или выполните `brew install python@3.13`, если у вас есть Homebrew. В Терминале проверьте `python3.13 --version` или `python3.12 --version`. При проблемах с SSL после установки с сайта откройте **Install Certificates.command** в папке выбранной версии Python в «Программах». [Загрузки для macOS](https://www.python.org/downloads/macos/).
- **Linux.** Установите Python и пакет поддержки venv для выбранной версии из репозиториев вашей системы. Например, на Ubuntu 24.04 доступны `sudo apt update` и `sudo apt install python3.12 python3.12-venv`. Проверьте `python3.13 --version` или `python3.12 --version`.

Установщики именно для 3.13.4 доступны на [странице выпуска Python 3.13.4](https://www.python.org/downloads/release/python-3134/).

## 2. Скачайте проект

На странице репозитория GitHub нажмите **Code → Download ZIP**, распакуйте архив и откройте папку, в которой находятся `setup.bat` и `setup.sh`. Либо скопируйте HTTPS-адрес из меню **Code**, выполните `git clone АДРЕС`, затем перейдите в скачанную папку командой `cd ИМЯ_ПАПКИ`.

## 3. Получите данные Telegram

### Токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot` и следуйте подсказкам. Придумайте отображаемое имя и уникальное имя пользователя, заканчивающееся на `bot`.
3. Скопируйте токен из ответа BotFather. Это значение для `BOT_TOKEN`. [Документация Telegram о создании ботов](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

### Доступ личного аккаунта (необязательно)

Для поиска по открытым каналам достаточно `BOT_TOKEN` и `OWNER_ID`. На приглашении `API_ID` нажмите **Enter**. Если в `.env` уже есть данные личного аккаунта, для работы только по ссылкам оставьте оба поля, `API_ID` и `API_HASH`, пустыми.

1. Откройте [my.telegram.org](https://my.telegram.org/) и войдите по номеру личного аккаунта. Введите код, который Telegram пришлёт для входа на сайт. [Инструкция Telegram по получению API ID](https://core.telegram.org/api/obtaining_api_id).
2. Нажмите **API development tools**. Если приложение уже создано, используйте его данные.
3. При создании укажите **App title** (например, `Perfume Search`), **Short name** (например, `perfumesearch`), **Platform** (`Desktop`) и краткое описание (например, `Personal search in subscribed channels`). Если поле **URL** необязательно, оставьте его пустым.
4. После сохранения скопируйте число **App api_id** и строку **App api_hash** в поля `API_ID` и `API_HASH`.

### ID владельца

`OWNER_ID` — числовой ID вашего личного аккаунта. При установке оставьте поле пустым и нажмите **Enter**. Скрипт попросит отправить `/start` вашему новому боту с личного аккаунта и нажать **Enter** в терминале. Затем он покажет число. Введите его в поле `OWNER_ID`. Пока определяете ID, держите бот остановленным и отправьте ему `/start` только со своего аккаунта. При запуске проект сверит ID с авторизованным личным аккаунтом.

## 4. Установите и запустите

**Windows.** Дважды нажмите `setup.bat` и заполните настройки. Затем дважды нажмите `start.bat`. Те же действия можно выполнить в PowerShell из папки проекта.

```powershell
.\setup.bat
.\start.bat
```

**macOS и Linux.** Откройте терминал в папке проекта. Если нужно перейти в неё вручную, используйте `cd "/путь/к/папке"`. Выполните эти команды.

```bash
bash setup.sh
bash start.sh
```

Установщик создаст локальное окружение `.venv`, загрузит зависимости и сохранит настройки в `.env`. Все поля, включая токен и API hash, видны при вводе. Заполненные поля сохраняются при повторной установке. Если доступны обе версии, при создании нового окружения установщик сначала ищет Python 3.13.

Чтобы перевести уже настроенный проект с 3.12 на 3.13, остановите бота, установите Python 3.13, переименуйте папку `.venv` в `.venv-312` и повторите установку. Следующий запуск будет использовать новое окружение. Настройки `.env` и сессия в папке `data/` сохраняются.

Если вы заполнили `API_ID` и `API_HASH`, при первом запуске в локальном терминале введите номер телефона в международном формате (например, с `+7`), код входа от Telegram и пароль двухфакторной авторизации, если Telegram его запросит. Код и пароль вводятся скрыто. В последующих запусках Telethon использует сохранённую сессию.

Когда в терминале появится «Бот запущен», откройте своего бота в Telegram и отправьте `/start`. Окно терминала должно оставаться открытым. Для остановки нажмите **Ctrl+C**. Для работы нужен включённый компьютер с интернетом.

## Как пользоваться

- **Найти аромат.** Введите название, например `Tom Ford Oud Wood`. Выберите объём из списка, укажите свой, например `7,5`, или выберите «Любой объём». Бот показывает до пяти предложений на странице. Кнопки под списком открывают соответствующие объявления.
- **Мои каналы.** Нажмите на канал, чтобы включить или исключить его из следующих поисков. «Обновить список» перечитает подписки. Нажмите «Добавить канал» и отправьте `@username`, `https://t.me/username` или `https://t.me/s/username`. После проверки бот сохранит канал в SQLite и будет искать по нему после перезапуска. Для следующей ссылки снова нажмите «Добавить канал». При подключённом личном аккаунте можно также добавлять каналы, доступные через него.
- **Настройки.** Выберите 7, 30, 90 дней или весь доступный период. По умолчанию установлено 30 дней.
- **История поиска.** Нажмите на запрос, чтобы повторить его с прежним объёмом и периодом по текущему списку каналов. Полные результаты кешируются на пять минут. «Обновить без кеша» запускает новые запросы к Telegram.
- **Отмена.** Кнопка под сообщением со статусом останавливает текущий поиск. Бот выполняет один поиск за раз.

Для сохранённых открытых каналов бот читает до 10 страниц публичного превью на канал за поиск и отмечает частичный результат при достижении лимита. Видимость более старых постов зависит от превью Telegram. Для остальных каналов подключённого аккаунта используется серверный поиск Telegram. В обоих случаях названия сверяются локально. При неоднозначной цене бот указывает «Цена не определена». Сортировка по цене идёт по возрастанию внутри каждой валюты в порядке ₽, €, $. Предложения без цены идут последними. Ссылки на приватные публикации открываются из аккаунта с доступом.

## Обновление

Остановите бота. Если скачали ZIP, распакуйте новую версию в отдельную папку и перенесите туда свои `.env` и `data/`. Если использовали Git, выполните `git pull` в папке проекта. Повторите установку и запустите бота обычным способом. Держите копию `.env` и `data/` в защищённом месте, если хотите сохранить настройки и историю.

## Если возникла ошибка

| Сообщение или симптом | Что сделать |
| --- | --- |
| Python 3.13 или 3.12 не найден | Установите нужную версию, откройте новое окно терминала и запустите установку снова. |
| Пустая настройка или неверный формат | Проверьте соответствующую строку в `.env`. Если файл скрыт, включите показ скрытых файлов. |
| Неверный токен | Скопируйте актуальный токен вашего бота из BotFather и замените `BOT_TOKEN` в `.env`. |
| Telegram отклонил код или пароль | Перезапустите бота, используйте свежий код и пароль двухфакторной авторизации. |
| Сессия отозвана или истекла | Остановите бота и снова запустите его для локального входа. Если ошибка повторяется, переместите `data/account.session` в защищённое место и запустите бота снова. |
| Бот не отвечает | Проверьте интернет, окно терминала и совпадение `OWNER_ID` с личным аккаунтом. Оставьте запущенной одну копию бота. |
| Поиск завершён частично или Telegram ограничил запросы | Проверьте доступ к каналам и повторите запрос после указанного интервала. Чтобы сократить поиск, можно выбрать более короткий период или исключить лишние каналы. |
| Предложений нет | Проверьте написание названия, список включённых каналов, объём и период. |

## Где хранятся данные

`.env` содержит токен и параметры приложения. В `data/bot.sqlite` хранятся настройки каналов, запросы и кеш с фрагментами публикаций. `data/account.session` содержит ключ действующей сессии Telegram. Владелец копии этого файла может использовать авторизованный сеанс личного аккаунта. Никому его не передавайте. Если файл попал к посторонним, завершите соответствующий сеанс в Telegram в разделе **Настройки → Устройства**. При утечке токена выпустите новый в BotFather.
